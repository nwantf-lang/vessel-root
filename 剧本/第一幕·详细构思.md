## 一、这一幕要完成什么

**时长：** 约 1 分 45 秒，14 个镜头，加片名 3 秒。

**一句话：** 什么都没有的地方，没有理由地发生了一下；有一下留下了折痕，再也平不回去；在折痕上，冒出了“有个我在”，初从纸里站起来，被锁进了“我”。

**观众看完这一幕应该感觉到：**
1. **空。** 开头的白不是“一个白色的地方”，而是什么都没有。速度很快，却哪儿也没去。
2. **突然。** 第一下是没有来源的，画面里找不到它从哪里来。
3. **回不去。** 折痕一旦出现，风想把它抹平，抹不平。这是全片第一次“不可逆”。
4. **爆发。** 光点亮起的那一下是整幕的重拍，前面一分钟的蓄力都为了它。
5. **被锁住。** 初站起来时很自由、很酷；可手腕上那圈线“咔”地扣上以后，观众要隐约觉得：这个人从此出不去了。

**这一幕的三个不可逆事件：**

| 时间 | 事件 | 留下的痕迹 |
|---|---|---|
| 0:36 | 第一道折痕 | 荧光橙的折线，后来变成初夹克上的折线 |
| 1:06 | 第一颗光点 | 光点所在的交点，变成初站起来的地方 |
| 1:30 | 锁住 | 初左手腕的荧光橙细线，戴到全片结束 |

## 三、视觉设计

### 1. 无（镜头 1–2）

- **白要“满”。** 整个画面过曝到纯白，没有暗角、没有地平线、没有任何物体。唯一在动的是极细的胶片颗粒。
- **速度靠声音和颗粒。** 画面上无法表现“往前冲”，就让颗粒向四周放射状掠过，再配上很强的风噪。观众感觉在高速前进，眼睛却找不到任何参照。
- **镜头 2 的“差点”。** 白里浮出一片极淡的灰影，大约 1 秒后又溶回白色。不要让它像一个物体，要像眼睛的错觉。

### 2. 纸面（镜头 3–8）

- **尺度：** 从太空看，纸面像行星表面，边缘有一点点弧度，远处有薄薄的大气光晕。纸面上有极细的纤维纹理，像大陆上的地貌。
- **冲击波：** 不是水波，是纸面本身被一股力推得鼓起又落下，鼓起的地方有一条亮白色的边。没有起点：第一道冲击波从画面中间凭空出现，向两侧扩散。
- **折痕：** 锐利的 V 形折线。折痕的谷底发出荧光橙色的光，像熔岩在缝里流。光只向前蔓延，前端最亮，后面稍暗但不熄灭。
- **山脉：** 很多折痕交错，隆起成山脉，山脊线上都有很细的荧光橙线，看起来像一张发光的电路图铺在行星上。

### 3. 光点（镜头 10）

- 荧光橙，正中心接近白色。
- 亮起时先向外炸出一圈薄薄的光环，扫过整片山脉，然后收回成一个稳定的点。
- 这是第一幕里最亮的一帧，调色时要比前面所有画面都亮一档。

### 4. 初的诞生（镜头 11）

- 纸面在光点处隆起，像一块布被从下面顶起。
- 纸的折页一层层向上翻折，“咔嗒咔嗒”地扣合，先折出脚、腿，再折出夹克的下摆、袖子、立领。
- 最后一折合上的瞬间，夹克变成真实的面料质感，初的脸出现，银白短发和那缕荧光橙挑染被风吹起。
- 节奏：前 7 秒升格慢动作，最后 2 秒突然提速，落在音乐的一个小重拍上。

### 5. 那块巨石（镜头 12）

- 灰白色、极高的一块巨石，立在远处两道山脊之间，像一座纪念碑。
- 它是第一幕里唯一一个“物体”，形状要简洁有力，没有纹理细节，像一块极简雕塑。

### 6. 锁（镜头 13）

- 初周身浮起一圈荧光橙细光，像一个呼啦圈那么大。
- 光圈先轻轻转动，然后快速收紧，绕到初的左手腕上，缩成一圈细线。
- 扣上的瞬间，画面轻轻一震，有一声清脆的金属音。

## 四、声音设计

| 镜头 | 声音层 |
|---|---|
| 1 | 强烈的风噪（高速前进感）+ 极低频的嗡鸣，二者都没有变化 |
| 2 | 风噪渐弱，灰影浮现时有一声几乎听不见的吸气 |
| 3 | 第一道冲击波：巨大而沉闷的“轰”，像远处的雷，但没有回声 |
| 4 | 冲击波从脚下掠过：近距离的呼啸，从左声道扫到右声道 |
| 5 | 许多下：此起彼伏的远雷，频率越来越密 |
| 6 | 折痕形成：一声撕裂般的纸张折断声，混着低音炮；光蔓延时有持续的“嘶嘶”声 |
| 7 | 风声扑向折痕，被折痕挡住，风声在折痕处被撕开 |
| 8 | FPV 俯冲的风声 + 嗡鸣升到最高 |
| 9 | **完全静音 2 秒** |
| 10 | 重拍：电子底鼓 + 一声明亮的合成器和弦 |
| 11 | 纸张翻折的“咔嗒”声，每一折一声，和鼓点对齐 |
| 12 | 风声回来，很轻 |
| 13 | 光圈转动的轻微嗡声，扣上时清脆的金属“咔” |
| 14 | 急速升空的风声，接全编制的上扬 |
| 片名 | 余音渐弱，黑场里留 1 秒安静 |

## 五、音乐

- **0:00–1:04：** 没有节拍，只有一层不断变厚的低频嗡鸣和合成器长音。每一道冲击波让嗡鸣往上推一点。
- **1:04–1:06：** 全部切断。
- **1:06：** 第一个重拍落下，电子鼓以约 100 BPM 进入，配一段简单、明亮、往上走的旋律。
- **1:12–1:24：** 鼓点和纸张翻折的“咔嗒”声对齐，每一拍一折。
- **1:30：** 锁上的那一下，旋律突然转到小调，提示“被锁住”。
- **1:38–1:42：** 全编制上扬到第一幕的最高点，在片名处戛然而止。

找配乐的关键词：`cinematic electronic, slow build, big drop, 100 BPM, minimal, epic`。

## 六、旁白

- **声音：** 年轻、干净、平静，不要播音腔，不要表演。像一个人在很近的地方对你说话。
- **语速：** 前一分钟很慢，句子之间留白；光点亮起后稍快。
- **混音：** 前一分钟旁白比音乐大；重拍之后旁白退后，让音乐冲上来。
- **“有个我在”** 这一句要在初站直、睁眼之前说完，像是这句话把初说出来的。

## 七、分镜

每条提示词后面都要接分镜剧本里的“统一风格后缀”。

### 镜头 1　无　（0:00–0:08，8 秒）

**生成方式：** 建议直接在剪辑软件里做：纯白画面 + 放射状运动的胶片颗粒 + 轻微的镜头抖动 + 风噪。AI 生成纯白画面时，常会自己加上云、雾或地平线。

如果一定要用 Seedance：
```
纯白色的画面，过曝，没有任何物体、没有地平线、没有云雾、没有远近，只有极细的胶片颗粒从画面中心向四周放射状高速掠过，营造极快速向前冲的感觉，镜头轻微抖动。
```

### 镜头 2　差点　（0:08–0:14，6 秒）

**生成方式：** 同样建议在剪辑软件里做：在白色画面上叠一层极淡的灰色柔光，1 秒内淡入、淡出。

### 镜头 3　第一下　（0:14–0:24，10 秒）

**生成方式：** 图生视频。先用文生图做首帧 **关键帧 K1**。

K1（文生图）：
```
从太空俯瞰一颗行星大小的白色纸面，纸面有极细的纤维纹理，边缘有轻微弧度和一层淡淡的大气光晕，背景是深靛蓝色的太空，画面极简。
```

视频提示词：
```
从太空俯瞰行星大小的白色纸面，镜头缓慢推近。纸面中央凭空鼓起一道巨大的环形冲击波，没有来源，冲击波的边缘是一条亮白色的线，迅速向四周扩散，扫过整个纸面，然后消失，纸面恢复完全平整。
```

### 镜头 4　从脚下掠过　（0:24–0:30，6 秒）

**生成方式：** 文生视频。
```
贴着白色纸面的超低空 FPV 视角，高速向前飞行。一道冲击波从镜头正下方呼啸掠过，纸面被推得鼓起又落下，鼓起处有一条亮白色的边。冲击波过后，纸面平整如初，什么也没留下。
```

### 镜头 5　许多下　（0:30–0:36，6 秒）

**生成方式：** 图生视频，首帧用 K1。
```
从太空俯瞰行星大小的白色纸面，纸面上许多不同位置同时出现冲击波，有大有小，有快有慢，每一道都扩散后消失，彼此不交叉，不留痕迹，像无声的闪电此起彼伏，频率越来越密。
```

### 镜头 6　折　（0:36–0:46，10 秒）

**生成方式：** 文生视频。可以多生成几次，挑折痕最锐利的一条。
```
贴着白色纸面的低空视角。一道冲击波重重砸在纸面上，这一次纸面被折出一道锐利的 V 形折痕。折痕的谷底亮起荧光橙色的光，像熔岩在缝里流动。光沿着折痕向前飞速蔓延，前端最亮，只向前，不回头。先是升格慢动作，然后突然加速，镜头跟着光的前端向前冲。
```

### 镜头 7　平不回去　（0:46–0:52，6 秒）

**生成方式：** 文生视频。这是“不可逆”最直接的一个镜头。
```
微距特写一道纸面上的锐利折痕，谷底发着荧光橙色的光，纸的纤维在折线处被压实、断裂。一阵强风从侧面扑过来，吹得折痕两侧的纸面微微颤动，想把它压平，但折痕纹丝不动，光也没有熄灭。风过去以后，折痕仍然清清楚楚。
```

### 镜头 8　山脉　（0:52–1:04，12 秒）

**生成方式：** 先用文生图做尾帧 **关键帧 K2**，再用首尾帧模式：首帧取镜头 6 的尾帧，尾帧用 K2。

K2（文生图）：
```
高空俯瞰行星大小的白色纸面，纸面上布满了交错的折痕，折痕隆起成连绵的山脉，每一条山脊线上都有很细的荧光橙色发光线，像一张发光的电路图铺在大地上，远处有深靛蓝色的天空。
```

视频提示词：
```
镜头沿着一道发着荧光橙光的折痕做 FPV 俯冲穿越，紧贴折痕飞行，然后急速拉升到高空。纸面上已经布满交错的折痕，隆起成山脉。一道冲击波从远处扫来，撞到一条折痕，被折痕带着拐了一个弯，沿折痕走了一段才离开。
```

### 镜头 9　停　（1:04–1:06，2 秒）

**生成方式：** 剪辑处理。把镜头 8 的最后一帧冻结 2 秒，画面略微压暗，配完全静音。

### 镜头 10　点燃　（1:06–1:12，6 秒）

**生成方式：** 图生视频，首帧用 K2。
```
高空俯瞰折痕山脉，镜头急速推向两道发光折痕相交的一点。交点处突然亮起一颗荧光橙色的光点，中心接近白色，光点向四周炸开一圈薄薄的光环，光环扫过整片山脉，然后光点稳定下来，持续发光。
```

### 镜头 11　站起来　（1:12–1:24，12 秒）

**生成方式：** 首尾帧。这是整幕最难的一个镜头。

- 首帧 **K3**（文生图）：
  ```
  近景，白色纸面上两道折痕的交点处有一颗荧光橙色的光点，纸面以光点为中心微微隆起，像一块布被从下面顶起。
  ```
- 尾帧 **K4**（图生图，以 @初（青年）定妆照为参考）：
  ```
  @初 站在白色折痕山脉之间，穿着白色折纸结构夹克，银白短发挑染一缕荧光橙，身体站直，闭着眼睛，脚下的纸面还保留着隆起的痕迹，四周飘着细小的纸屑，低角度仰拍，锐利的边缘光。
  ```

视频提示词：
```
光点处的纸面隆起，纸的折页一层层向上翻折、咔嗒咔嗒地扣合，先折出脚和腿，再折出白色折纸夹克的下摆、袖子和立领，@初 从纸面里站起来。前半段升格慢动作，纸屑在 @初 身边飞散；最后一折合上的瞬间画面突然提速，夹克变成真实的面料，@初 的银白短发被风吹起。低角度仰拍，镜头环绕半圈。
```

**如果生成效果不好：** 拆成两个 6 秒镜头。第一个只拍纸面翻折到腰部，第二个从腰部翻折到 @初 站直，两个镜头用尾帧接首帧。

### 镜头 12　那　（1:24–1:30，6 秒）

**生成方式：** 图生视频，首帧用 K4。参考图 @初（青年）。
```
@初 睁开眼睛，眼神从迷茫变得锐利。镜头切到 @初 的过肩视角：远处两道山脊之间，立着一块极高的灰白色巨石，形状简洁，像一座纪念碑。再切回 @初 的面部特写，表情从疑惑变成确定。
```

### 镜头 13　锁　（1:30–1:38，8 秒）

**生成方式：** 图生视频。参考图 @初（青年）。
```
中景，@初 站在折痕山脉间，望着远处的巨石。@初 周身浮起一圈荧光橙色的细光环，光环先轻轻转动，然后快速收紧，绕到 @初 的左手腕上，缩成一圈细细的荧光橙线。扣上的瞬间画面轻轻一震。@初 低头看了一眼手腕，又抬起头，神情平静而确定。
```

### 镜头 14　升空　（1:38–1:42，4 秒）

**生成方式：** 图生视频，首帧取镜头 13 的尾帧。
```
从 @初 的头顶急速向上升空，@初 越来越小，折痕山脉越来越广，一直升到太空。最后只能看到行星大小的白色纸面上，布满发光的折痕，其中一个交点上有一颗极小的荧光橙色光点。
```

### 片名　（1:42–1:45，3 秒）

黑场，正中淡入白色片名“折痕”。片名下方有一道荧光橙细线从左向右划过，划过后不消失。片名在剪辑软件里做。

## 八、制作顺序

1. **先做定妆照：** @初（青年）。
2. **再做 4 张关键帧：** K1 行星纸面、K2 折痕山脉、K3 光点隆起、K4 初站立。四张图先放在一起看，确认颜色和质感统一，再开始生成视频。
3. **先生成最难的镜头 11。** 它决定这一幕能不能成立。如果反复生成都不理想，就用“拆成两个镜头”的方案。
4. **再按顺序生成** 3、4、5、6、7、8、10、12、13、14。
5. **镜头 1、2、9 和片名** 在剪辑软件里做。
6. **最后对音乐剪：** 先把配乐铺好，以 1:06 的重拍为锚点，前后对齐。

## 九、风险与对策

| 风险 | 对策 |
|---|---|
| 纯白画面被加上云雾或地平线 | 镜头 1、2 改在剪辑软件里做 |
| 冲击波被生成成水波 | 提示词里强调“纸面被推得鼓起”“纸是干的”；用 K1 做首帧锁住质感 |
| 荧光橙颜色漂移 | 后期统一调色；只让“以为”相关的元素保留这个颜色 |
