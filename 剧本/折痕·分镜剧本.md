# 折痕 · 分镜剧本

> 改编自小说《[折痕](../折痕.md)》
> 用于 Seedance 逐个场景生成视频
> 周 peng & Claude
> 2026-11-27（第二版：年轻化、高能量、时尚、宏大、不可逆）

---

## 这一版的基调

| 要求 | 在画面上怎么做 |
|---|---|
| **年轻** | 主角都二十出头。造型是未来原始风：折纸结构的廓形夹克、工装、麻绳当配饰。 |
| **活力** | 镜头一直在动：FPV 穿越、甩镜、环绕、升格慢动作接突然提速。人物会奔跑、跳跃、滑下沙丘。 |
| **时尚** | 用时装大片的打光和走位：锐利的边缘光，人物出场像秀场亮相。颜色只用白、深靛蓝和荧光橙。 |
| **宏大** | 尺度极大：那张纸像行星那么大，折痕从太空看像山脉，画的圈从高空看像一圈冲击波。 |
| **不可逆** | 不用倒放，也不让东西回到原样。每一场都留下一个永久的痕迹，一直带到最后。结尾回到开头那片白，可白纸上已经有了一道折痕。 |

### 不可逆的痕迹链

每一场留下的东西，后面都不会消失：

| 场景 | 留下的痕迹 | 后来出现在 |
|---|---|---|
| 2 | 第一道荧光橙折痕 | 3 场：变成初夹克上的折线 |
| 3 | 初手腕上的一圈荧光橙细线 | 一直戴到 12 场 |
| 7 | 圈右边补过的那段，比原来粗、比原来亮 | 12 场：老年初夹克右侧有一道粗粗的缝补线 |
| 8 | 绳结和刻痕 | 9 场起越来越多 |
| 10 | 观潮人从年轻到白发 | 被划掉的字留在岩石上 |
| 11 | 地图上改过的一笔 | 12 场：地图摊在初和问身边 |
| 12 | 初的白发 | 结尾：白纸上留着一道折痕 |

## 怎么用这份剧本

1. **一个镜头一次生成。** 每个镜头 4–15 秒，Seedance 2.0 可以直接生成。版本支持更长的时长时，可以把同一场景里相邻的镜头合并成一次多镜头生成。
2. **先做角色定妆照。** 用文生图（比如 Seedream）按下面的“角色设定”做出正面、全身、纯色背景的定妆照。之后有人物的镜头都用图生视频，上传定妆照，提示词里用 @ 指明角色。
3. **每条提示词后面都接同一段风格后缀。** 复制粘贴，不要改。
4. **标了“接上一镜尾帧”的**，把上一个视频的最后一帧截下来，当作这一镜的首帧。
5. **字和旁白后期加。** 生成的汉字容易错，提示词里统一写了“画面中无文字”。旁白、字幕、地图上的字都在剪辑时加。
6. **音乐决定剪辑点。** 先按下面的“音乐结构”找好配乐，再按重拍剪镜头。

## 统一风格后缀

```
风格：时尚大片与史诗电影的结合，高对比，以纯白和深靛蓝为主色，荧光橙作为唯一的点缀色，锐利的边缘光，镜头运动有力，变速节奏，尺度宏大，IMAX 质感，16:9，画面中无文字、无水印。
```

**视觉母题：** 整个世界是一张巨大的纸。荧光橙代表“以为”：第一道折痕、第一颗光点、初手腕上的线，都是这个颜色。

## 音乐结构

| 场景 | 音乐 | 能量 |
|---|---|---|
| 0–2 | 低频嗡鸣，越来越响，没有节拍 | 蓄力 |
| 3 | **第一个重拍落下**，电子鼓进入 | 爆发 |
| 4–5 | 轻快的打击乐，约 100 BPM | 上升 |
| 6 | **第二个重拍**：两个圈相撞 | 爆发 |
| 7 | 情绪段落；裂开时**音乐突然全部断掉**，补好后节拍重新进来，比之前更重 | 断裂、重建 |
| 8 | 用水滴声和刻石声做采样，拼成节奏 | 律动 |
| 9 | 山顶的鼓就是全片**最大的重拍**，约 120 BPM，人群齐声 | 最高点 |
| 10 | 宏大的弦乐加电子低音 | 史诗 |
| 11 | 全编制合奏 | 辽阔 |
| 12 | 一层层撤掉，最后只剩一声心跳 | 归零 |

## 角色设定

**初（青年）**
```
二十出头，中性面孔，轮廓清晰，银白色短发，前额挑染一缕荧光橙。穿一件超大廓形的白色折纸结构夹克，面料硬挺像厚纸，带锐利的折线；黑色束脚裤，赤脚。眼神锐利、好奇。
```
从场景 3 起，左手腕多一圈荧光橙细线。

**初（老年）**
```
同一个人到了七十多岁。银白长发在脑后束起，脸上有深纹。还是那件白色折纸夹克，已经发旧发灰，右侧有一道粗粗的荧光橙缝补线。左手腕仍有那圈荧光橙细线，已经褪色。
```

**迟**
```
二十出头，中性面孔，深肤色，黑发高高束成发髻。穿深靛蓝色工装风长外套，肩上和腰间缠着打了结的麻绳当配饰，戴一枚银色耳骨夹。眼神凌厉，嘴角带笑。
```

**问**
```
七八岁的孩子，短发，大眼睛，穿一件荧光橙色的宽大连帽外套，赤脚。
```

**观潮人（青年）**
```
二十岁左右，晒得黝黑，深色卷发，上身穿黑色潜水服，外披一件白色宽松罩衫，手握一块尖石。
```
老年时：同一个人，白发编成一条长辫，罩衫褪色。

## 场景 1 · 一带而过

### 1-1　冲击波　（10 秒）

```
多镜头切换。镜头一：从太空视角俯瞰一张行星大小的白色纸面，一道巨大的冲击波涟漪从纸面上横扫而过，扫过以后纸面恢复平整。镜头二：贴近纸面的低空 FPV 视角，又一道涟漪从镜头下方呼啸而过，消失。镜头三：远处同时有许多道涟漪出现又消失，像无声的闪电。
```
- 旁白：后来，有一下。没有理由。事情就是发生。发生了，又像没发生。
- 音乐：嗡鸣变响，每道涟漪带一声低沉的呼啸。

## 场景 2 · 一道折痕

### 2-1　折下去　（10 秒）

```
贴着白色纸面的超低空视角。一道涟漪猛地砸下来，这一次纸面被折出一道锐利的折痕，折痕边缘亮起荧光橙色的光。光沿着折痕向前飞速蔓延，像一道裂开的闪电，只向前，不回头。升格慢动作，然后突然提速。
```
- 旁白：有一次不一样。那一下过去的时候，留下了一点什么。
- 音乐：一声巨大的纸张折裂声，嗡鸣骤升。

### 2-2　山脉　（12 秒）

接上一镜尾帧。
```
镜头沿着那道发着荧光橙光的折痕做 FPV 俯冲穿越，然后急速拉升到高空。从高空看，纸面上已经布满了折痕，折痕隆起成连绵的山脉，山脊上有荧光橙色的细线。另一道涟漪撞到折痕，被折痕带着拐了一个弯。
```
- 旁白：于是有了“前面”，也有了“后来”。折过的纸，再也平不回去了。
- 音乐：嗡鸣到最高点，突然停住。

## 场景 3 · 以为

### 3-1　点燃　（6 秒）

```
高空俯瞰折痕山脉，镜头急速推向两道折痕的交点。交点处“砰”地亮起一颗荧光橙色的光点，光向四周炸开一圈光环，然后稳定下来，持续发光。
```
- 旁白：就在某一个弯上——
- 音乐：**第一个重拍落下**，电子鼓进入。

### 3-2　站起来　（12 秒）

参考图：@初（青年）。接上一镜尾帧。
```
光点所在的纸面猛地隆起，纸的褶皱一层层翻折、咔嗒咔嗒地扣合，变成一件白色折纸结构夹克，@初 从纸面里站起来。升格慢动作：纸屑在 @初 身边飞散。@初 站直的一瞬间画面提速，@初 睁开眼睛，锐利的边缘光打在脸上。低角度仰拍，环绕半圈。
```
- 旁白：有个我在。
- 音乐：鼓点推进。

### 3-3　锁上　（10 秒）

参考图：@初（青年）。
```
@初 猛地转头，看向远处一块巨大的灰白色巨石，巨石立在折痕山脉之间。过肩镜头，巨石在远处。切回 @初 面部特写，表情从疑惑变成确定。一圈荧光橙色的细光从 @初 周身收拢，缠到 @初 的左手腕上，变成一圈细线，“咔”一声锁住。
```
- 旁白：有个那在。这确定来得太快了，快得初来不及怀疑。从这一刻起，初就被锁在了“我”里面。
- 音乐：锁住时一声清脆的金属音。

## 场景 4 · 石头

### 4-1　还是那块　（10 秒）

参考图：@初（青年）。
```
@初 在折痕山脉间奔跑跳跃，越过一道道山脊，冲到那块巨石前急停。@初 抬头看着巨石，眨眼。多镜头快速切换：每眨一次眼，光线就变一次，清晨的冷蓝、正午的白、傍晚的橙，巨石的影子跟着移动，巨石还是那块巨石。
```
- 对白（初）：还是那块石头。
- 音乐：轻快的打击乐进入。

### 4-2　认错　（10 秒）

参考图：@初（青年）。
```
@初 看见远处又有一团灰白色，全速冲过去，滑步急停。那只是地面上一片影子。@初 伸手去抓，手直接穿过了影子。@初 愣住，低头看自己的手。镜头从全景甩到手部特写。
```
- 旁白：原来认，也会认错。这是第一次有东西不听初的。
- 音乐：停一拍。

## 场景 5 · 圈

### 5-1　画圈　（12 秒）

参考图：@初（青年）。
```
@初 弯腰把一根手指插进沙地，然后开始奔跑，手指在沙地上划出一道发光的线，绕出一个巨大的圆。无人机从低处急速升高，越升越高，看出那是一个直径上百米的完美圆圈，@初 停在圆心。圈内的沙子变暖，圈外变冷。
```
- 旁白：圈里面是我。圈外面是别的。画完以后，初就再也走不出这个圈了。不是因为圈有多高，是因为初已经相信了它。
- 音乐：节拍加快。

### 5-2　路就是感觉　（12 秒）

参考图：@初（青年）。
```
@初 在圆圈里走出有节奏感的步伐，像一段舞。镜头环绕跟拍。@初 每踏过一段，地面就亮起不同的颜色：一段暖橙，一段冷靛蓝，一段纯白。光随着脚步延伸，在圈里留下一条发光的轨迹，轨迹不会消失。
```
- 旁白：初以为感觉是走路时碰到的东西。其实，走过的那条路本身，就是感觉。
- 音乐：踩点。

### 5-3　我的一天　（10 秒）

参考图：@初（青年）。
```
夜晚，星空巨大。@初 坐在圆心，面前浮现出许多块半透明的发光画面：清晨的光、正午的影子、傍晚的风。它们原本散在四周，@初 抬手一划，它们飞速排成一条长长的时间线，向远处延伸，照亮 @初 的脸。
```
- 对白（初）：这是我的一天。
- 旁白：那条线是初自己排的。白天发生的时候，它们并没有排着队。
- 音乐：节拍收住，留一段合成器长音。

## 场景 6 · 迟

### 6-1　越画越大　（12 秒）

```
太空视角俯瞰沙漠。一个发光的圆圈一次次向外扩张，像一圈圈冲击波，越来越大，越来越快。镜头急速下降。圆圈最外的那条线，撞上了画面另一侧另一个正在扩张的靛蓝色圆圈。两圈相撞的地方迸出一道强光。
```
- 旁白：初的圈越画越大。圈大了，初觉得更安全。可是圈的边也更长了，碰到别的东西的地方也更多了。
- 音乐：急速上升的音阶。

### 6-2　亮相　（8 秒）

参考图：@迟。
```
两圈相碰处的强光中，@迟 从靛蓝色的圈里走出来，像时装秀的亮相：步伐有力，麻绳配饰随步伐甩动，逆光勾出锐利的轮廓。@迟 停住，抬眼，一脸吃惊。正面低角度，慢慢推近。
```
- 旁白：两个人都以为，世界上只有自己。
- 音乐：**第二个重拍**。

### 6-3　有了二　（10 秒）

参考图：@初（青年）、@迟。
```
@初 和 @迟 隔着两圈相碰的那道光缝对视，风把沙子卷成两道旋涡，分别绕着两人旋转。两人同时向前迈出一步，脚落地时光缝亮了一下。镜头以两人为中心快速环绕一整圈。
```
- 旁白：就在两个圈碰上的那一下，初第一次真正知道了“我”是什么。一个人的时候，没有“一”。碰到迟，才有了“二”。
- 音乐：全编制进入。

## 场景 7 · 依靠

### 7-1　背靠背　（10 秒）

参考图：@初（青年）、@迟。
```
一场巨大的沙尘暴从地平线压过来。@初 和 @迟 背靠背站在两个相交的圆圈里，沙暴撞到两人身边时被劈成两半，从两侧呼啸而过，两人站的地方风平浪静。升格慢动作，两人的衣角和麻绳被风吹得笔直。
```
- 旁白：一个人画圈很累。两个人挨着，对方的圈就替自己挡住了一边。
- 音乐：鼓点强而稳。

### 7-2　来往　（15 秒）

参考图：@初（青年）、@迟。多镜头。
```
多镜头快速切换，节奏明快。镜头一：@初 和 @迟 从高高的沙丘上一路滑下来，笑着。镜头二：两人蹲在巨石前，@迟 教 @初 认石头的纹路。镜头三：@初 偷偷模仿 @迟 画圈的手势。镜头四：日落时两人坐在山脊上，背影剪影，影子连在一起。
```
- 旁白：来往多了，初慢慢知道了迟是怎么画圈的、怎么认石头的、怕什么、喜欢什么。知道迟的时候，初也忍不住拿自己去比。
- 音乐：情绪段，旋律最温暖的地方。

### 7-3　右边　（10 秒）

参考图：@初（青年）、@迟。
```
@初 正在画圈，手从左边开始。@迟 站在一旁，随口说了一句话，抬手指向 @初 的右边。@初 的手猛地停住，慢慢转头看向自己从没看过的右边。面部大特写，瞳孔收缩。
```
- 对白（迟）：你画圈的时候，总是先护着左边。右边你从来不看。
- 音乐：**音乐在这句话后全部断掉。**

### 7-4　裂开，补上　（15 秒）

参考图：@初（青年）。多镜头。
```
多镜头切换。镜头一：夜晚，@初 的圈在右边轰然裂开，裂缝像玻璃一样向外炸开，裂缝里不是黑，也不是空，是一种缓缓流动、说不出颜色的浅灰。镜头二：@初 站在裂缝边缘，被那片浅灰照着。镜头三：@初 转身，用全身的力气把沙推回去，补上的那段圈线比原来粗一倍，发出更亮的荧光橙。镜头四：天亮，@初 回头看了一眼补过的地方，然后转身向外狂奔，继续画圈。
```
- 旁白：圈补好了，比原来厚了一层。初说：“我不会再让这件事发生了。”这句话，本身就是新的一层圈。那道裂缝补上了，可原来那条细细的线，再也回不来了。
- 音乐：裂开时完全无声；补上时节拍重新进来，比之前更重。

## 场景 8 · 绳与水滴

### 8-1　绳结　（10 秒）

参考图：@初（青年）、@迟。多镜头。
```
多镜头快速切换。镜头一：@初 和 @迟 站在一块长石两端，各自张开双手比长度，@迟 的手更宽，两人对着对方大笑着争论。镜头二：微距，@初 的手飞快地在麻绳上打出一个结，用力拉紧。镜头三：两根绳子并排甩在石面上，一根湿的明显短了一截。
```
- 对白（初）：我们都用这根绳子量。
- 音乐：用绳子拉紧的声音做节拍。

### 8-2　一滴，一道　（15 秒）

参考图：@迟、@初（青年）。多镜头。
```
多镜头切换，跟着节拍剪。镜头一：@迟 把一片绿叶垫在岩缝下。镜头二：超微距升格，岩缝里一滴水慢慢鼓起、变圆、坠落，砸在叶面上溅成一朵皇冠形水花。镜头三：@初 用尖石在岩壁上刻下一道，火星迸出。镜头四：镜头沿岩壁快速横移，刻痕一道接一道，排满整面岩壁，没有一道被抹掉。
```
- 对白（迟）：一滴，就是一份。
- 旁白：今天的这一滴，和昨天的那一滴，不是同一滴。昨天的那一段，已经过去了。可是只要这件事一次又一次地发生，就可以把它们当成一样长。
- 音乐：水滴声和刻石声采样成节奏。

## 场景 9 · 别人的绳

### 9-1　千人　（15 秒）

```
史诗级远景。清晨，一座巨大的灰白色石碑立在山脚，石面上刻着一道长长的直线。成千上万穿着白色、靛蓝和荧光橙衣服的年轻人，从四面八方的山脊上涌来，手里都拿着打了结的绳子。无人机从石碑顶端掠过，然后下降到人群中，人们把绳子贴到石碑的刻线上比对，有人发现自己的绳子短了一截，耸耸肩，在旁边刻下差了多少。
```
- 旁白：差别没有被擦掉，只是被记下来了。这比假装一样更有用。
- 音乐：人群声与鼓声渐起。

### 9-2　鼓　（10 秒）

```
多镜头切换。镜头一：正午，山顶上一个人高高举起鼓槌，砸向一面巨大的兽皮鼓。镜头二：太空视角，一圈肉眼可见的冲击波从山顶向四周的山谷扩散，掀起一圈环形的尘土。镜头三：山两侧的人群在冲击波到达的瞬间，同时在石头上刻下一道，山那边的人慢了半拍。
```
- 旁白：声音翻过山要花一点时间。他们后来也算进去了。
- 音乐：**全片最大的重拍**，每一下鼓都踩在剪辑点上。

### 9-3　对不上　（15 秒）

参考图：@初（青年）、@迟。多镜头。
```
多镜头切换。镜头一：夜晚，三堆篝火，三拨年轻人围坐，把刻着记号的木板摊开对照，表情困惑但没有争吵。镜头二：@迟 带着几个人打着火把，在一段陡峭的山路上用绳子重新丈量，一路跑上山脊。镜头三：@初 在一张巨大的兽皮地图上，把一段山路的线条重重地加长了一笔，炭笔划过的那一刻，篝火同时腾起。
```
- 旁白：大家没有说谁撒谎。大家坐下来，一段一段地查。那一天，他们的地图改了一笔。
- 音乐：鼓点转为低沉的推进。

## 场景 10 · 潮

### 10-1　刻潮，一年又一年　（12 秒）

参考图：@观潮人（青年）。
```
巨浪拍打的海边，一块平坦的黑色礁石。@观潮人 每次涨潮都在礁石上刻下一道记号。延时摄影：潮水涨了又退，日月飞速交替，礁石上的记号越来越密，@观潮人 的卷发慢慢变成白发，编成一条长辫，年轻的脸变老。只向前，不倒回。最后定格在刻满记号的礁石和白发的侧脸。
```
- 旁白：一个人在石头上刻下每次涨潮的时候。刻了很多年。
- 音乐：宏大的弦乐进入。

### 10-2　潮来了　（12 秒）

参考图：@观潮人（老年）。
```
海边，一大群年轻人围着白发的 @观潮人。@观潮人 举起手，对着太阳比出三根手指。切到第二天：一道巨大的潮水准时涌上海滩，浪墙高过人群，人群欢呼着向后奔跑。只有 @观潮人 站在原地，平静地摇头，说了一句话。
```
- 对白（观潮人）：明天，潮会在太阳偏西三指的时候来。
- 对白（观潮人，第二天）：这不是海的规矩，是我们看出来的样子。
- 音乐：弦乐推到高点。

### 10-3　别擦　（15 秒）

参考图：@观潮人（老年）。多镜头。
```
多镜头切换。镜头一：狂风暴雨中的海边，月亮在不寻常的位置，海面平静得反常，潮水没有来。镜头二：一个年轻人抓起石块，要去磨掉礁石上的记号。镜头三：@观潮人 一把按住年轻人的手。镜头四：@观潮人 在旧记号旁边刻下新的一行，火星在雨中迸出；礁石上一些旧记号被划了一道横线，但仍清清楚楚，没有被磨掉。
```
- 对白（年轻人）：刻的字错了，擦掉吧。
- 对白（观潮人）：别擦。在旁边再刻一行。
- 旁白：被划掉的字也没有磨掉，就留在那里。能被划掉的字，才是真的在说话。
- 音乐：暴风雨与弦乐交织。

## 场景 11 · 地图

### 11-1　展开世界　（13 秒）

```
一张巨大的兽皮地图在广阔的平原上被几百个人拉着展开，像一面巨帆铺满大地。无人机从地图一角起飞，贴着地图表面高速飞行：正中间是山脚的大石碑，四周是绳结标出的土地、山路、海岸线、潮水的记号，墨线新旧叠加，处处有修改过的痕迹。镜头急速拉升，整张地图在大地上展开。画面中无文字。
```
- 旁白：人们把所有的绳子、水滴、鼓声、潮水，都画到了一张很大的兽皮上。这就是他们的世界。

### 11-2　空白，和还在吵　（12 秒）

```
镜头贴着兽皮地图飞到边缘：地图外大片空白，什么也没画，空白一直延伸到地平线。镜头转到一处：两条不同颜色的线画在同一个地方，彼此不重合。一只年轻的手握着炭笔，在空白的边缘添上新的一笔，这一笔向外延伸出去。画面中无文字。
```
- 旁白：地图的边上，有大片空白：这里我们还不知道。有两个地方，到现在也对不上：还在吵。一张不让人改的地图，才是死的。
- 后期字幕：空白处叠加“这里我们还不知道”，两条线之间叠加“还在吵”。
- 音乐：辽阔的长音。

## 场景 12 · 问

### 12-1　世界是从哪里来的　（10 秒）

参考图：@初（老年）、@问。
```
海边的高崖上，黄昏，巨大的夕阳。兽皮地图铺在崖顶。@初（老年）坐在地图旁，白色折纸夹克已经发灰，右侧有一道粗粗的荧光橙缝补线，左手腕的荧光橙细线已经褪色。穿荧光橙外套的 @问 坐在旁边，看看地图，抬头问了一句话。逆光双人中景，镜头缓慢环绕。
```
- 对白（问）：世界是从哪里来的？
- 音乐：撤到只剩钢琴。

### 12-2　从头讲起　（12 秒）

参考图：@初（老年）、@问。多镜头。
```
多镜头极速闪切。镜头一：@初（老年）开口讲述。镜头二：@问 的眼睛大特写，瞳孔里飞速闪过：横扫纸面的冲击波、荧光橙的折痕、炸开的光点、从纸里站起来的人、巨大的圆圈、两圈相撞、劈开的沙暴、坠落的水滴、山顶的鼓、巨浪、铺满大地的地图。镜头三：@问 听得入神，一动不动。
```
- 旁白：初想了很久，然后从头讲起。
- 音乐：前面所有段落的旋律以极快的速度闪回一遍。

### 12-3　找不到　（15 秒）

参考图：@初（老年）、@问。
```
@问 想了想，又问了一句。@初（老年）张开嘴，像要回答，却停住了，眼神慢慢向内收，像在找什么，找了很久。海风吹动白发。然后 @初 的脸上慢慢露出笑容，轻声说了一句话。@问 也跟着笑了。面部大特写正反打，最后一个镜头是两人的笑脸剪影衬着落下的夕阳。
```
- 对白（问）：那现在，在讲这个故事的，是谁？
- 对白（初）：不知道。没找到。
- 音乐：完全无声，只有风。

### 12-4　有个我在　（12 秒）

参考图：@问。
```
一阵海风从崖下猛地吹上来，掀起兽皮地图的一角，像第一场那道横扫纸面的冲击波。镜头急速推近 @问 的脸，再推进 @问 的瞳孔：瞳孔深处“砰”地亮起一颗荧光橙色的光点，和第三场的光点一模一样。光点稳定的一瞬间，画面切进一片纯白，镜头再次以极快的速度向前冲——但这一次，白色里有一道细细的荧光橙折痕，从镜头下方一闪而过。
```
- 旁白：就在某一个弯上，问的心里，冒出了一个念头：有个我在。
- 音乐：一声心跳。黑场。

## 剪辑提示

- **首尾：** 12-4 的结尾和 0-1 用同样的运镜，但白里多了一道折痕。故事回到了开头，却回不到原样。
- **荧光橙只给“以为”：** 折痕、光点、手腕的线、补过的圈、问的外套。调色时不要让别的东西出现这个颜色。
- **节奏曲线：** 0–2 场蓄力；3 场和 6 场各一次爆发；7 场中段完全断掉；9 场是最高点；12 场一路降到一声心跳。
- **不倒放：** 全片不使用倒放、回卷、复原的画面。转场可以用甩镜、匹配剪辑和闪白。
- **旁白：** 一个年轻、干净、不表演的声音读完全片。
