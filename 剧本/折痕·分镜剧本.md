> 改编自小说《[折痕](../折痕.md)》

> 2026-11-27

---

## 怎么用这份剧本

1. **一个镜头一次生成。** 每个镜头标了时长，都在 4–15 秒之内，Seedance 2.0 可以直接生成。如果你用的版本支持更长的时长，可以把同一场景里相邻的镜头合并成一次多镜头生成。
2. **先做角色参考图。** 先用文生图（比如 Seedream）按下面的“角色设定”做出初、迟、问、老人的正面定妆照。之后每个有人物的镜头都用“图生视频”，上传对应的参考图，并在提示词里用 @ 指明角色，脸和衣服才能前后一致。
3. **每条提示词都带上同一段风格后缀。** 后缀见下一节，复制粘贴，不要改。
4. **连续的镜头用尾帧接首帧。** 标了“接上一镜尾帧”的，把上一个视频的最后一帧截下来，作为这一镜的首帧。
5. **旁白和字幕后期加。** AI 视频里生成的汉字常常会错，地图上的字、旁白、字幕都在剪辑时加。提示词里都写了“画面中无文字”。
6. **对白可选。** 有对白的镜头写了台词。如果生成的配音不理想，就只生成画面，台词后期配。

## 统一风格后缀

每条提示词的最后都接上这一段：

```
风格：东方极简，宣纸纹理，低饱和的灰白、米色与靛蓝，柔和自然光，35mm 胶片颗粒，电影感，16:9，节奏缓慢，画面安静，画面中无文字、无水印。
```

**视觉母题：** 整个世界是一张纸。第一道折痕后来变成地形，人从折痕里站起来，衣褶像纸褶。风吹过时，总像第一章那道涟漪。

## 角色设定

先用文生图做出下面四张定妆照。每张都要求：正面、半身、光线均匀、纯色背景。

**初（青年）**
```
一位二十多岁的人，中性面孔，清瘦，黑色短发微乱，赤脚，穿未染色的粗麻长袍，袍子的褶皱像折过的宣纸，眼神安静而好奇。
```

**初（老年）**
同一个人到了七十多岁：白发，脸上有深纹，袍子更旧，颜色更浅。

**迟**
```
一位二十多岁的人，中性面孔，肤色较深，黑发在头顶束成一个结，穿靛蓝色粗布长袍，颈上挂一根打了结的麻绳，表情机敏。
```

**问**
```
一个七岁左右的孩子，圆脸，短发，穿灰褐色粗羊毛短衣，赤脚，眼睛很大。
```

**海边的老人**
```
一位年迈的人，皮肤被海风吹得黝黑，灰白长发编成一条辫子，穿褪色的麻衣，手里握着一块尖石。
```

## 场景 0 · 没有之前

### 0-1　白　（12 秒）

```
极近距离的一片纯白纸面，看不到边缘，也看不出远近。白色在极其缓慢地变化，分不清是亮还是暗，像在呼吸。镜头几乎不动，只有非常轻微的推近。没有任何物体，没有任何人。
```
- 旁白：这个故事要从“之前”讲起。可是那时候，连“之前”也没有。
- 声音：几乎无声，极低的底噪。

### 0-2　未分　（10 秒）

接上一镜尾帧。
```
同一片纯白纸面，明暗以极慢的速度起伏，有一瞬间似乎出现了一点阴影，又立刻融回白色，像是“有”和“没有”还没分开。最后画面完全静止。
```
- 旁白：有和没有，还没分开。就这样。
- 声音：无声。

## 场景 1 · 一带而过

### 1-1　涟漪　（8 秒）

接上一镜尾帧。
```
平整的白色纸面上，忽然有一道很浅的涟漪从画面左边掠到右边，像风吹过水面，但纸是干的，画面里没有风也没有水。涟漪过去以后，纸面恢复得完全平整，什么也没有留下。俯拍，镜头不动。
```
- 旁白：后来，有一下。没有理由。事情就是发生。
- 声音：一声极轻的气流声，随即消失。

### 1-2　许多次　（10 秒）

```
同一张白色纸面，俯拍。许多道浅浅的涟漪在不同位置出现、掠过、消失，有快有慢，彼此不相交，每一道都不留痕迹。像延时摄影，节奏像呼吸。
```
- 旁白：这样的一下，后来还有过很多次。数不清，因为没有谁在数。
- 声音：此起彼伏的轻微气流声。

## 场景 2 · 一道折痕

### 2-1　留下了　（10 秒）

```
微距特写白色纸面。一道涟漪经过，这一次在它经过的地方，纸面留下了一道细细的折痕。一束低角度侧光扫过，折痕的一侧亮，一侧有细长的影子。镜头缓慢推近折痕。
```
- 旁白：有一次不一样。那一下过去的时候，留下了一点什么。
- 声音：一声极轻的纸张折动声。

### 2-2　前面与后来　（12 秒）

接上一镜尾帧。
```
第二道涟漪从远处掠来，碰到那道折痕，在折痕处拐了一个弯，沿着折痕走了一段才离开。折痕慢慢变浅，但没有消失。镜头缓慢拉远升高，纸面上出现越来越多的折痕，从高处看像山脊和河道的地形。
```
- 旁白：于是有了“前面”，也有了“后来”。它还是会消失。只是这一次，消失的路上多拐了几个弯。
- 声音：低沉的风声慢慢进来。

## 场景 3 · 以为

### 3-1　一点光　（8 秒）

```
纸面地形的俯视图。镜头缓慢推向两道折痕相交的一点。在交点处，亮起一颗很小、很柔和的暖白色光点，光点轻轻闪了一下，然后稳定下来。
```
- 旁白：就在某一个弯上，发生了一件小事。
- 声音：一声很轻的、像吸气一样的声音。

### 3-2　站起来　（12 秒）

参考图：@初（青年）。接上一镜尾帧。
```
光点所在的纸面慢慢隆起，纸的褶皱一层层变成粗麻长袍的衣褶，@初 从纸面里缓缓站起来，像是一直在那里，只是刚刚醒来。站直以后，@初 睁开眼睛。中景，镜头从低角度缓慢上摇。
```
- 旁白：有个我在。
- 声音：纸张舒展的声音，风声。

### 3-3　那　（10 秒）

参考图：@初（青年）。
```
@初 转头，看向远处一团灰白色的东西。镜头切到 @初 的过肩视角，那团灰白色在远处纸面地形上，轮廓模糊。再切回 @初 的面部特写，表情从疑惑变成确定。@初 周围的空气里，有一圈几乎看不见的光边轻轻合拢。
```
- 旁白：有个那在。这确定来得太快了，快得初来不及怀疑。从这一刻起，初就被锁在了“我”里面。
- 声音：风声停住一瞬。

## 场景 4 · 石头

### 4-1　还是那块　（10 秒）

参考图：@初（青年）。
```
一块灰白色的石头立在纸质地面上。@初 蹲在石头前，看了很久，然后闭上眼睛，又睁开。闭眼前后，光线从清晨的冷光变成稍暖的光，石头的影子挪了一点。@初 微微点头。中景，镜头固定。
```
- 对白（初，轻声）：还是那块石头。
- 声音：远处的风声。

### 4-2　影子　（12 秒）

参考图：@初（青年）。
```
@初 看见远处又有一团灰白色，起身走过去。走近以后，那只是地面上一片影子。@初 停下，伸手去摸，手穿过了影子，摸到的是平平的地面。@初 愣住，低头看自己的手。跟拍，最后停在 @初 的手部特写。
```
- 旁白：原来认，也会认错。它很小，可它是第一次有东西不听初的。
- 声音：脚步声，停顿后的安静。

## 场景 5 · 圈

### 5-1　画圈　（12 秒）

参考图：@初（青年）。
```
俯拍。@初 赤脚站在沙地上，弯腰用一根手指在身边画出一个完整的圆圈，画完后站到圆心，慢慢直起身。圆圈画好的一瞬间，圈内的沙子颜色略暖，圈外略冷。
```
- 旁白：圈里面是我。圈外面是别的。画完以后，初就再也走不出这个圈了。不是因为圈有多高，是因为初已经相信了它。
- 声音：手指划过沙子的声音。

### 5-2　路就是感觉　（12 秒）

参考图：@初（青年）。
```
@初 在圈里慢慢走，从东边走到西边，从石头旁走到圈边。镜头侧面跟拍。@初 走过的地方，地面的光色随之变化：一段暖黄，一段冷蓝，靠近石头的一段是柔和的白。@初 的表情随光色细微变化。
```
- 旁白：初以为感觉是走路时碰到的东西。其实，走过的那条路本身，就是感觉。
- 声音：脚步声，音色随光色变化。

### 5-3　我的一天　（12 秒）

参考图：@初（青年）。
```
夜晚，@初 坐在圈的中心，抱着膝盖。@初 面前的空中浮现出几片半透明的画面：早上的光、中午的影子、傍晚的风吹过沙地。它们本来散在空中各处，然后慢慢移动，排成一条横线。@初 的脸被这些画面微微照亮。
```
- 对白（初）：这是我的一天。
- 旁白：那条线是初自己排的。白天发生的时候，它们并没有排着队。
- 声音：夜里的虫声。

## 场景 6 · 迟

### 6-1　圈越画越大　（12 秒）

```
高空俯拍沙地。地上有一个圆圈，圆圈中心有一个小小的人影。延时摄影：人影一次次沿着更外圈的位置重新画圈，圈越来越大。最后一次画出的圈边，碰到了画面另一侧的另一个圆圈。
```
- 旁白：初的圈越画越大。圈大了，初觉得更安全。可是圈的边也更长了，碰到别的东西的地方也更多了。
- 声音：一次次划沙的声音，越来越快。

### 6-2　两个圈　（10 秒）

参考图：@初（青年）、@迟。
```
地面视角。两个沙地圆圈的边缘相碰。@初 站在左边的圈里，@迟 站在右边的圈里，两人同时抬头看见对方，都愣住了。正反打：@初 的吃惊特写，@迟 的吃惊特写。
```
- 旁白：两个人都以为，世界上只有自己。
- 声音：风声骤停。

### 6-3　有了二　（10 秒）

参考图：@初（青年）、@迟。接上一镜尾帧。
```
两个圈相碰的地方，沙地上亮起一道细细的光缝。@初 和 @迟 分站光缝两侧，各自小心地向前迈了一步。双人中景，镜头从侧面缓慢横移。
```
- 旁白：就在两个圈碰上的那一下，初第一次真正知道了“我”是什么。一个人的时候，没有“一”。碰到迟，才有了“二”。
- 声音：一声低而长的弦音。

## 场景 7 · 依靠

### 7-1　挡风　（10 秒）

参考图：@初（青年）、@迟。
```
@初 和 @迟 并肩站在两个相交的圆圈里。风从画面右侧吹来，沙子只在两人圈外的一侧飞扬，两人站的地方很安静。两人肩膀放松下来。中景。
```
- 旁白：一个人画圈很累。两个人挨着，对方的圈就替自己挡住了一边。省力。
- 声音：风声，在两人身边变小。

### 7-2　来往　（15 秒）

参考图：@初（青年）、@迟。多镜头。
```
多镜头切换。镜头一：@初 和 @迟 分享一捧水。镜头二：@迟 教 @初 怎样认一块石头，两人蹲在石头前。镜头三：@初 看着 @迟 画圈的手势，若有所思。镜头四：黄昏里两人背对镜头坐着，影子挨在一起。
```
- 旁白：来往多了，初慢慢知道了迟是怎么画圈的、怎么认石头的、怕什么、喜欢什么。知道迟的时候，初也忍不住拿自己去比。
- 声音：轻柔的环境音，偶尔的笑声。

### 7-3　右边　（12 秒）

参考图：@初（青年）、@迟。
```
@初 正在沙地上画圈，手从左边开始。@迟 站在一旁看着，随口说了一句话，抬手指向 @初 圈的右边。@初 的手停住，慢慢转头看向自己右边从没看过的那一侧。面部特写，眼神晃动。
```
- 对白（迟，随口）：你画圈的时候，总是先护着左边。右边你从来不看。
- 旁白：初从没看过自己的右边。
- 声音：对白之后安静。

### 7-4　裂开，补上　（15 秒）

参考图：@初（青年）。多镜头。
```
多镜头切换。镜头一：夜晚，@初 圈的右边裂开一道缝，缝里不是黑色，也不是空的，是一种难以形容的、微微流动的浅灰。镜头二：@初 跪在裂缝前，犹豫地看着它。镜头三：@初 用手把沙推回去，把裂缝补上，补过的那段圈线明显比原来粗了一层。镜头四：天亮，@初 站起来，又开始向外画圈。
```
- 旁白：圈补好了，比原来厚了一层。初说：“我不会再让这件事发生了。”这句话，本身就是新的一层圈。
- 声音：裂开时一声低闷的声音；补上时沙子的声音；天亮时风声回来。

## 场景 8 · 绳与水滴

### 8-1　绳结　（12 秒）

参考图：@初（青年）、@迟。
```
@初 和 @迟 站在一块长石头两端。@初 张开双手比划石头的长度，@迟 张开的双手比 @初 的更宽，两人争论。然后 @初 拿起一根麻绳，在绳上打了一个结，把绳子拉直贴在石头上。
```
- 对白（初）：我们都用这根绳子量。
- 声音：争论的语气声，绳子拉紧的声音。

### 8-2　两根绳　（10 秒）

参考图：@初（青年）。
```
特写：两根打了结的麻绳并排放在一块平石上，一根干燥，一根被雨打湿、颜色更深、略短。@初 的手把两根绳子的端点对齐，绳结的位置有一点错开。镜头缓慢推近错开的地方。
```
- 旁白：只有两根对得上的时候，才算数。
- 声音：雨后滴水声。

### 8-3　一滴，一道　（15 秒）

参考图：@迟、@初（青年）。多镜头。
```
多镜头切换。镜头一：@迟 在石缝下放一片绿叶。镜头二：微距，石缝里的水慢慢鼓起、变圆、落在叶子上，溅起细小水花。镜头三：@初 用尖石在旁边的岩面上刻下一道短线。镜头四：岩面上的短线一道接一道排成一排，镜头横移。
```
- 对白（迟）：一滴，就是一份。
- 旁白：今天的这一滴，和昨天的那一滴，不是同一滴。可是每一滴都一样。只要这件事一次又一次地发生，就可以把它们当成一样长。
- 声音：水滴声与刻石声交替，形成节奏。

## 场景 9 · 别人的绳

### 9-1　大石头　（15 秒）

```
清晨，山脚下立着一块巨大的灰白色石头，石面上刻着一道长长的直线。许多穿着不同颜色粗布衣服的人从四面八方走来，每人手里都有一根打了结的绳子，排队把绳子贴在石面的刻线上比对。远景缓慢推到中景，可以看到有人看到自己的绳子短了一截，露出意外的表情。
```
- 旁白：差别没有被擦掉，只是被记下来了。这比假装一样更有用。
- 声音：人群低语，风声。

### 9-2　鼓声　（12 秒）

```
多镜头切换。镜头一：正午，山顶上有人举起鼓槌敲响一面兽皮鼓。镜头二：一圈看得见的淡淡声波从山顶向两侧山谷扩散。镜头三：山这边的人和山那边的人，在声波到达时各自在石头上刻下一道线，山那边的人稍晚一点。
```
- 旁白：声音翻过山要花一点时间。他们后来也算进去了。
- 声音：一声浑厚的鼓声，带回声。

### 9-3　对不上　（15 秒）

参考图：@初（青年）、@迟。
```
多镜头切换。镜头一：三拨人围坐在火堆旁，摊开各自刻着数字记号的木板，彼此对照，表情困惑但不争吵。镜头二：几个人沿着一段山路用绳子重新丈量，@迟 在其中。镜头三：@初 在一张兽皮地图上，把一段山路的线条画得更长，改了一笔。
```
- 旁白：大家没有说谁撒谎。大家坐下来，一段一段地查。那一天，他们的地图改了一笔。
- 声音：火堆噼啪声，低声交谈。

## 场景 10 · 潮

### 10-1　刻潮　（12 秒）

参考图：@海边的老人。
```
海边一块平坦的大岩石。@海边的老人 用尖石在岩面上刻下一道记号，抬头看潮水。延时摄影：潮水涨了又退，一天一天过去，岩面上的记号越来越多，老人的头发越来越白。最后定格在刻满记号的岩面和老人的侧脸。
```
- 旁白：一个老人在石头上刻下每次涨潮的时候。
- 声音：海浪声，延时中加速。

### 10-2　潮来了　（12 秒）

参考图：@海边的老人。
```
海边，一群村民围着 @海边的老人。老人抬手指向天上的太阳，比出三根手指。切到第二天：潮水准时涌上沙滩，村民欢呼。老人却平静地摇头，说了一句话。
```
- 对白（老人）：明天，潮会在太阳偏西三指的时候来。
- 对白（老人，第二天）：这不是海的规矩，是我们看出来的样子。
- 声音：浪声，欢呼声。

### 10-3　别擦　（15 秒）

参考图：@海边的老人。多镜头。
```
多镜头切换。镜头一：狂风大作的海边，月亮在不寻常的位置，潮水没有按时来。镜头二：一个年轻人拿起石块要去磨掉岩面上的记号。镜头三：@海边的老人 伸手按住年轻人的手。镜头四：老人在旧记号旁边刻下新的一行；岩面上有些记号被划了一道横线，但仍清晰可见，没有被磨掉。
```
- 对白（年轻人）：刻的字错了，擦掉吧。
- 对白（老人）：别擦。在旁边再刻一行。
- 旁白：被划掉的字也没有磨掉，就留在那里。能被划掉的字，才是真的在说话。
- 声音：狂风，浪声，刻石声。

## 场景 11 · 地图

### 11-1　兽皮　（12 秒）

```
室内，一张巨大的兽皮地图在地上缓缓展开。镜头从高处贴着地图慢慢滑过：正中间画着山脚下的大石头，周围是用绳结标出长度的土地、山路、海岸线、潮水的记号。墨线有新有旧，有些地方明显被修改过。画面中无文字，只有图形和记号。
```
- 旁白：人们把所有的绳子、水滴、鼓声、潮水的字，都画到了一张很大的兽皮上。这就是他们的世界。
- 声音：兽皮展开的摩擦声。

### 11-2　空白与还在吵　（12 秒）

```
镜头滑到兽皮地图的边缘：大片空白，什么也没画。再滑到一处：两条不同颜色的线画在同一个地方，彼此不重合，中间留着一块空隙。最后一只手拿着炭笔，在地图上小心地添了一笔。画面中无文字。
```
- 旁白：兽皮的边上，有大片空白：这里我们还不知道。有两个地方，到现在也对不上：还在吵。一张不让人改的地图，才是死的。
- 后期字幕：在空白处叠加“这里我们还不知道”，在两条线之间叠加“还在吵”。
- 声音：炭笔划过的声音。

## 场景 12 · 问

### 12-1　世界是从哪里来的　（12 秒）

参考图：@初（老年）、@问。
```
海边的黄昏，兽皮地图铺在沙地上。@初（老年）坐在地图旁，@问 坐在旁边，看着地图，然后抬头看向 @初，开口问了一句话。双人中景，暖色逆光。
```
- 对白（问）：世界是从哪里来的？
- 声音：远处的浪声。

### 12-2　从头讲起　（15 秒）

参考图：@初（老年）、@问。多镜头。
```
多镜头切换。镜头一：@初（老年）的嘴唇在动，正在讲述。镜头二：@问 的眼睛特写，瞳孔里依次映出一道掠过纸面的涟漪、一道折痕、一个光点、沙地上的圆圈、两个圈相碰、一滴水落在叶子上、潮水涌来、一张兽皮地图。镜头三：@问 听得入神。
```
- 旁白：初想了很久，然后从头讲起。
- 声音：讲述的低语声，被浪声盖住，听不清内容。

### 12-3　找不到　（15 秒）

参考图：@初（老年）、@问。
```
@问 想了想，又问了一句。@初（老年）张开嘴，像是要回答，却停住了，眼神慢慢向内收，像在找什么，找了很久。然后 @初 的脸上慢慢露出笑容，轻声说了一句。@问 也跟着笑了，笑得有点莫名。面部特写正反打。
```
- 对白（问）：那现在，在讲这个故事的，是谁？
- 对白（初）：不知道。没找到。
- 声音：对白之间有很长的停顿，只有浪声。

### 12-4　有个我在　（12 秒）

参考图：@问。
```
海风从画面左边吹来，掠过兽皮地图和刻满记号的岩石，地图的边角轻轻掀起又落下，像第一章那道掠过纸面的涟漪。镜头缓慢推近 @问 的脸，再推近 @问 的眼睛：瞳孔深处亮起一颗很小、很柔和的暖白色光点，和第三章的光点一模一样。光点稳定下来的瞬间，画面淡入一片纯白纸面，与第一个镜头相同。
```
- 旁白：就在某一个弯上，问的心里，冒出了一个念头：有个我在。
- 声音：风声一带而过，然后完全安静。

## 剪辑提示

- **首尾呼应：** 12-4 结尾的纯白纸面，和 0-1 用同一帧画面。观众应该感觉故事回到了开头。
- **反复出现的三个画面：** 掠过的涟漪（1-1、12-4）、暖白光点（3-1、12-4）、纸褶变衣褶（3-2）。剪辑时保持它们的颜色、速度和音效一致。
- **节奏：** 场景 0 到 3 极慢，几乎没有剪切；场景 7 到 10 加快，人和事情变多；场景 12 再慢下来。
- **旁白：** 建议一个声音读完全片，声音平静、不带表演。
